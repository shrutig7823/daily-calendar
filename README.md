# My Daily Calendar

A tiny calendar with a bulleted to-do list for every day. When you open it, it
shows (and sends a browser notification with) everything you have to do today.

- Click any date to see/edit that day's to-dos
- Data is stored in your browser (localStorage) — nothing leaves your device
- Click "Enable notifications" once to allow desktop notifications

Run locally: open `index.html`, or `python -m http.server`.
